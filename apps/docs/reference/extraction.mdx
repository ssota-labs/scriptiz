Schemas are defined in `packages/mcp-tools/src/schemas.ts`.

Scriptiz MCP focuses on **single YouTube videos and Shorts** (watch URLs). Playlist-only and channel-tab URLs are rejected with `UNSUPPORTED_URL`.

## `extract_content`

Enqueues a metadata + caption (or STT) extraction **job** for a YouTube **video** URL.

**Input**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `url` | string | yes | Supported `watch` / Shorts URL |
| `language` | string | no | Default: server `DEFAULT_TRANSCRIPT_LANGUAGE` / context default |
| `allowSttFallback` | boolean | no | Use STT when no captions |
| `forceRefresh` | boolean | no | If `true`, re-queue even when a transcript already exists |
| `uiLocale` | string | no | Optional BCP-47 tag retained for API compatibility |

**Success (summary)**  
`jobId`, `status`, `resourceId`, `alreadyExtracted?`

**Error codes (examples)**  
`VALIDATION_ERROR`, `UNSUPPORTED_URL`, `DUPLICATE_JOB` (retryable), yt-dlp-related codes

## `get_extraction_status`

**Input:** `{ "jobId": string, "uiLocale"?: string }`

**Success:** `jobId`, `status`, `resourceId?`, `errorCode?`, `errorMessage?`, `updatedAt`  
**Errors:** `JOB_NOT_FOUND`, `VALIDATION_ERROR`

## `list_available_languages`

Returns **available caption languages** from `yt-dlp` metadata (useful before saving).

**Input:** `resourceId` **or** `url` (if both, `resourceId` wins). URL must be a **single-video** YouTube URL.

**Success:** `{ "languages": [ ... ] }`  
**Errors:** `VALIDATION_ERROR` (neither `resourceId` nor `url`), `NOT_FOUND`, `UNSUPPORTED_URL`

## Common error codes

| Code | Meaning |
|------|---------|
| `VALIDATION_ERROR` | Zod validation failed |
| `NOT_FOUND` | Resource missing |
| `UNSUPPORTED_URL` | YouTube URL not supported (only single-video URLs) |
| `JOB_NOT_FOUND` | Unknown job id |
| `DUPLICATE_JOB` | Job already in progress for resource |
| `PARSE_FAILED` | Failed to parse yt-dlp response |
| `YTDLP_TIMEOUT` / `YTDLP_FAILED` / `VIDEO_UNAVAILABLE` | Extractor / network / availability |
| `STT_PROVIDER_INVALID` / `STT_API_KEY_MISSING` | STT env / keys misconfigured when captions are missing and STT fallback runs |
| `STT_FILE_TOO_LARGE` / `STT_TIMEOUT` / `STT_HTTP_ERROR` | STT audio limit, request timeout, or provider HTTP error |

`INTERNAL` and unknown yt-dlp errors may include a detailed `message`.
